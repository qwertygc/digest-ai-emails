Options de Digest IA

Fournisseur LLM Mistral, OpenAI (ChatGPT), Anthropic (Claude), Google (Gemini), ou n'importe quel service compatible OpenAI (OpenRouter, Groq, Ollama, LM Studio, llama.cpp, vLLM…). Pré-rempli selon le fournisseur, modifiable. Pour un service compatible OpenAI, indiquez l'URL qui se termine avant « /chat/completions » (ex. http://localhost:11434/v1 pour Ollama). Laissez tel quel pour les fournisseurs connus. Conservée uniquement dans le stockage local de Thunderbird, sur votre machine. Identifiant exact du modèle chez le fournisseur (ex. mistral-small-latest, gpt-4o-mini, claude-sonnet-4-5, gemini-2.0-flash).
Revue Ex. : Nucléaire, Photographie. Les sections correspondantes remontent en tête du digest (★) dès qu'un message s'y rattache.
Mémoire des traitements Les regroupements et synthèses déjà payés sont réutilisés tant que les messages concernés sont inchangés : un second lancement identique ne consomme aucun token. Changer de fournisseur ou de modèle vidait naturellement la mémoire.
